# Security Policy

MediaForge is designed to run locally on your machine.

By default, the app should only be used from:

`127.0.0.1`

Do not expose MediaForge directly to the public internet.

## Notes

- Only download media from sources you trust.
- Be careful with links from unknown users.
- Keep Python, FFmpeg and dependencies updated.
- Report security issues privately when possible.
